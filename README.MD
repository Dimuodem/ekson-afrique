Overview
This is a premium corporate website for Ekson Afrique Ltd, a Kenyan engineering and procurement company. The website is designed to communicate trust, professionalism, engineering excellence, and innovation, comparable to world-class companies like Siemens, Honeywell, Bosch, and Schneider Electric.

Typography
Font: Inter (Google Fonts)

Headings: Bold with generous spacing

Body: Readable paragraphs with optimal line-height

Logo
The logo is an inline SVG in the navigation. To replace it:

Replace the SVG code in <a class="logo"> tag

Or use an image: <img src="your-logo.png" alt="Ekson Afrique" />

Social Media Links
Update social media URLs in:

index.html (footer and contact sections)

All pages/*.html files
